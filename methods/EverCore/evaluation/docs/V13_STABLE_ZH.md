# v1.3-stable

本标记冻结2026-10-29阿里云实际运行的v1.3接口实现，包括此前未提交的两项修复。发布不重启、不修改正在运行的阿里云Full。

## 相比原v1.3的变更

1. 增加Add与视觉调用的脱敏诊断日志：仅包含固定错误码、状态、结束原因、token数、描述条数/长度和带密钥散列的请求/图片指纹。不记录密钥、原始请求、图片、caption正文、问题或答案。
2. 历史图片描述数组超量时，校验所有条目，沿用大小写和空白归一化去重，然后只保留前4条。空数组保持合法；非数组、非字符串、空描述、单条超过1,200字符仍报错，包含第5条之后的非法内容也不跳过。无效输出不作为成功描述缓存或提交记忆。

诊断字段中`too_many_descriptions`仅说明上游数组条数超量；在合法条目去重截取成功后，它不意味着Add失败。实际失败另有`image_details_invalid`与`add_failed`事件。

## 保持不变

- 模型：视觉和查询图片描述使用gpt-4o-mini；文本向量使用text-embedding-v4；重排使用Cohere rerank-v3.5，均为API调用。
- 历史图片细节提示词、temperature=0、max_tokens=768、detail=high与JSON模式不变。
- 网络错误及429/5xx的原有两次HTTP尝试与间隔不变；不增加模型推理或无限重试。
- 共享接纳并发16，同用户写入/检索串行，繁忙请求排队。
- 每路向量候选128，图片描述与文本双路召回后融合，一次重排，展开原始消息后按消息ID去重，最多min(top_k,15)条；媒体预算不变。
- SQLite结构、索引身份与既有数据兼容；不得自动删除生产数据。
- 健康检查仍返回raw-rag-aml-v1.3，不靠修改字符串冒充部署了新算法。

## 核验与实验边界

发布时应逐文件核对`evaluation/src/aml/*.py`与阿里云实际源码，而不只检查Git HEAD或健康检查字符串。描述截取修复及原接口回归共173项离线测试通过；这不等于完成赛事平台的新一轮Smoke或Full。

本地公开Mem-Gallery若声称与stable一致，必须直接调用相同的AML Add/Search实现和相同模型配置。旧`multimodal.full_run`加Qwen重排的实验不是该实现，即使同样写着15条或使用同一个Embedding模型。

如离线实验明确用Qwen3-Reranker-4B替换Cohere，应标记为`v1.3-stable-qwen4b`模型变体：直接复用stable的AML引擎与Add/Search封装，仅注入本地重排后端。不得将该变体宣称为与阿里云完全相同的模型设置，也不得因此更换正在运行的生产Full。

公开数据离线Reader及LLM-Judge属于评估工具，不是Add/Search服务的一部分，也不证明与赛事平台内部Reader完全一致。新实验使用全新目录，不混用旧预测、caption、向量、索引或评分。不得将参考答案、类别或clue传入检索器；这些只用于生成答案后的评价。
