# ATM 来源兼容与完整消息去重

核查日期：2026-10-27。本文区分原生数据文件、AML 接口输入和方法质量，不使用平台
运行时的评测记忆、问题或答案进行分析、调参。

## ATM-Bench 接入结论

公开格式依据：

- https://github.com/JingbiaoMei/ATM-Bench/blob/main/docs/data.md
- https://agentmemoryleaderboard.ai/api-guide

ATM 原生来源包含图片、视频及邮件。邮件具有 id、timestamp、short_summary、detail；
图片和视频的文本表示包含媒体路径、timestamp、location_name、short_caption、caption、
ocr_text、tags。这些原生字段不是 AML Add 的额外顶层字段。

现有服务无需 ATM 专用分支即可处理以下符合 AML 契约的输入：

| 来源 | AML 允许的表示 | 现有处理与返回 |
| --- | --- | --- |
| 邮件 | 正文及来源字段编码为字符串或 text 部件；时间可另放消息 timestamp | 原文参与切片、向量召回与重排，完整原文和来源时间返回 |
| 图片 | 来源说明、OCR、地点等放 text 部件，原图放内联 image_url | 原文和模型图片描述参与文本检索；返回原文及原图字节，保持部件顺序 |
| 视频的文本表示 | 视频 ID、时间、地点、描述等放字符串或 text 部件 | 全部提供的文本字段参与检索，返回完整输入文字 |
| 视频的抽帧表示 | 视频/帧标识、帧时间和对应 image_url 组成有序部件 | 按图片处理与检索，返回原始帧及对应文字，保持帧与文字的绑定 |

用公开 schema 构造、不含真实评测题目的四类样例，在修改检索流程前走 Add/Search
均通过；另一个反例确认原始 video_url 被明确拒绝，且没有模型调用。这五项测试
确认的是服务收到这些规范表示后的保存、索引与返回，不是对 ATM 答题质量的保证。
因此不修改当前 Add、媒体解析、原始存储或 ATM 特定逻辑。

限制：

- AML 当前只规定 text/image_url，不规定原始 MP4/video_url。原始视频文件和原生
  ATM JSON 不能直接作为接口请求体发送。它们如何变为接口内容由平台转换流程决定；
  本次没有验证平台的冻结转换代码，不声称所有视频帧、音频或 EXIF/GPS 都会送到服务。
- 原生来源 ID、OCR、地点等只有包含在输入 text 中才能保留；服务不凭空补造未收到
  的元数据。顶层未声明 metadata 字段会被拒绝，不应把它当作字段保留通道。
- 图片目前仍是描述转文本向量召回和文本重排，不是原生视觉向量或视觉重排；
  格式兼容不等于细粒度视觉信息、跨来源推理和最终得分均已验证。

## v1.1：一次重排、完整消息去重、后置限额

新的线上 Search 流程：

1. 保持原有 query/options 处理和最多 128 个 chunk 的向量召回不变。
2. 只进行一次 chunk 重排，top_n 等于实际召回候选数，获取全部候选的排序；
   不在此处截取 15 个 chunk。
3. 按排序遍历 chunk 的 source_ids，按原始 message_id 去重，保留首次出现的顺序；
   不比较 chunk 文本，也不将不同消息的相同文字合并。
4. 每个唯一 message_id 形成一条完整消息证据，继承首次命中的 chunk 重排分数，
   即命中它的最高分；同分按首次出现顺序排列，不对完整消息再次重排。
5. 选择最多 min(top_k, 15) 条消息，返回原始文字及图片部件。重复或超媒体预算
   的来源跳过后继续向后遍历，直到足额或候选耗尽，不在去重前截断。
   返回 id 是稳定的原始 message_id，不再是可能随切片更新改变的 chunk_id。

同一消息无论被多少个相同或部分重叠的 chunk 命中，最多返回一次。
不同时间、不同位置或不同会话的消息仍然是不同来源，即使正文
相同也都保留。原始单条消息内重复出现的图片或文字不删除，避免改写原始证据。
例如前 20 个 chunk 来自同一消息，只留一条，继续从第 21 个 chunk 补充不同来源。
去重后不足 15 条时按实际候选数返回，不生成替代证据，不额外扩大向量召回范围。

正常非空 Search 仅调用一次重排，网络重试另计；上游错误
仍明确报错，不静默退回未重排结果。空用户及 top_k=0 不调用模型。媒体预算按完整
消息选择，单条消息不截断，图片字节不改变。索引和持久化结构未变化，无需重新 Add。

## 测试与版本边界

`tests/test_aml_api.py` 新增 ATM 表示兼容性和去重回归，包含长消息多 chunk、
部分重叠来源、同文但不同原始消息、原始图文完整性、chunk 分数继承与排序、
去重后向第 15 个之后补足、媒体预算跳过后补足、top_k、稳定 ID 及重排失败行为。
测试要求重排模型只被调用一次，且 top_n 为实际召回候选数，而不是请求 top_k。
使用替身模型，不消耗付费模型额度；这不是完整 ATM 质量评测。
